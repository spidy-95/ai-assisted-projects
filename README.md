`trivia-battle-source.zip` contains the application source with folder structure preserved. Extract before running. Requires Node.js >=22.13, pnpm, and configured Cloudflare D1 infrastructure; it cannot run directly on static GitHub Pages. See `TRIVIA_SETUP.md`.
